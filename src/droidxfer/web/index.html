Connect over Wi-Fi

On the phone, open Settings › System › Developer options › Wireless debugging, turn it on and tap Pair device with QR code. The phone and the Mac must be on the same Wi-Fi network.

In Wireless debugging, tap Pair device with pairing code and enter the IP address, port and 6-digit code shown on the phone.

After pairing, go to the Connect tab and use the IP address & port from the main Wireless debugging screen (a different port from pairing). Paired phones usually reconnect automatically.
